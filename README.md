# swift-claude — Orbit macOS widget

A WidgetKit-based macOS widget project, scaffolded for Xcode.

## Why this repo has no `.xcodeproj`

This project was scaffolded from a Linux container, which cannot run Xcode
or compile Swift for Apple platforms. Instead of hand-writing a fragile
`.xcodeproj` (a mostly-generated, Xcode-internal format), the project is
defined declaratively in [`Orbit/project.yml`](Orbit/project.yml) using
[XcodeGen](https://github.com/yonaskolb/XcodeGen). On your Mac, XcodeGen
turns this into a real, correctly-wired Xcode project.

## Setup (on macOS)

1. Install Xcode (from the App Store or developer.apple.com) and open it once
   to accept the license / install components.
2. Install XcodeGen:
   ```sh
   brew install xcodegen
   ```
3. Generate the Xcode project:
   ```sh
   cd Orbit
   xcodegen generate
   open Orbit.xcodeproj
   ```
4. In Xcode, select the `OrbitApp` target → **Signing & Capabilities** and
   set your Apple Developer **Team**. Repeat for the `OrbitWidgetExtension`
   target. (You can also set `DEVELOPMENT_TEAM` directly in `project.yml`
   and re-run `xcodegen generate`.)
5. Both targets already declare the App Group
   `group.com.orbit.app` in their entitlements (see `project.yml`) so the
   host app and the widget can share data via `UserDefaults(suiteName:)`.
   Make sure this App Group is enabled for your team in your Apple Developer
   account, or change the identifier to one you own.
6. Build & run the `Orbit` scheme, then add the "Orbit" widget from macOS's
   widget gallery (right-click the desktop → Edit Widgets, or via Notification
   Center).

## Project layout

```
Orbit/
  project.yml                  # XcodeGen project spec (source of truth)
  OrbitApp/                    # Host application (SwiftUI, macOS app target)
    OrbitApp.swift
    ContentView.swift
    Info.plist
    OrbitApp.entitlements      # generated by xcodegen from project.yml
    Assets.xcassets/
  OrbitWidget/                 # Widget extension target
    OrbitWidgetBundle.swift    # @main WidgetBundle
    OrbitTimelineProvider.swift
    OrbitWidgetView.swift      # SwiftUI views + Widget configuration
    Info.plist
    OrbitWidget.entitlements   # generated by xcodegen from project.yml
  Shared/                      # Code shared by both targets
    OrbitEntry.swift           # Data model + App Group storage helper
```

## Customizing the widget

- Edit `Orbit/OrbitWidget/OrbitWidgetView.swift` for layout/content, and
  `Orbit/OrbitWidget/OrbitTimelineProvider.swift` for how/when it refreshes.
- Widget sizes currently supported: **small** and **medium**
  (`.supportedFamilies([.systemSmall, .systemMedium])` in `OrbitWidgetView.swift`).
  Add `.systemLarge` there if you want a large layout too.
- `Shared/OrbitEntry.swift` defines `OrbitSnapshotData` and a small
  `OrbitSharedStore` helper for passing data from the host app to the widget
  via the App Group. Replace `OrbitSnapshotData` with your real data model.
- Use `WidgetCenter.shared.reloadTimelines(ofKind: "OrbitWidget")` from the
  host app after updating shared data to force the widget to refresh.

## Note on this environment

The container this was scaffolded in cannot install the Swift toolchain
(`download.swift.org` is blocked by the environment's egress policy) or run
Xcode, so none of this has been compiled or previewed. Validate it by
generating and opening the project in Xcode on a Mac.
